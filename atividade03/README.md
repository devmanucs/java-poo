# Atividade 03 - Heranca em Java

Sistema bancario criado para demonstrar os principais conceitos de heranca em Java.

## Estrutura

- `Conta`: superclasse abstrata com os dados e comportamentos comuns.
- `ContaCorrente`: permite usar um limite adicional no saque.
- `ContaPoupanca`: permite aplicar rendimento ao saldo.
- `ContaSalario`: limita a quantidade de saques.
- `Main`: demonstra a criacao e o uso das contas com polimorfismo.

## Executar

No diretorio `atividade03`, execute:

```bash
javac *.java
java Main
```
